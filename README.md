# Tesla Roadster：回家

浏览器里的一局下班通勤。你开着带冷气推进器的概念跑车「Rocky」，从公司停车场沿主路开回家。路上有晚高峰、铁路道口、Tesla Semi 车队，还有环道和倒挂出坡。开过家门口那条线就到家。

```bash
pnpm install
pnpm dev
```

默认地址是 http://127.0.0.1:3000 。服务只绑在本机，端口被占用时会直接失败。

## 操作

- `W` / `S`，或上下方向键：油门、刹车倒车
- `A` / `D`，或左右方向键：地面转向；在空中是侧喷偏航
- `Shift`：后喷加速
- `Space`：底部喷气抬升
- `Q` / `E`：左右喷气横移
- `R`：回到安全点
- `Esc` 或 `P`：暂停
- `M`：静音

手柄用同一套动作：左摇杆驾驶，A 抬升，RT 后喷，LB / RB 横移，Y 回到安全点，Start 暂停。
